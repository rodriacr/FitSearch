# Adaptaciones para el DAS 1.18

Estas figuras resumen las asociaciones y cardinalidades del modelo de clases y las relaciones del esquema implementado. Se omitieron atributos de las cajas para mantener legibilidad al insertarlas en Word; no reemplazan las fuentes integrales 02/04 ni el diccionario de datos. Las reglas de eliminación e índices se consultan en el diccionario. El DAS identifica esta adaptación en las ilustraciones 2 y 4. Mermaid 10.9.3, tema base, Arial; SVG y PNG de 3200 px. Las demás figuras usan las fuentes integrales o la adaptación de secuencia ya documentada en DAS 1.17.
