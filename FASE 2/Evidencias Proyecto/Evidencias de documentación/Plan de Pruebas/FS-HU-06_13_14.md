| Caso | Resultado |
| --- | --- |
| Agenda sin sesión o con rol incorrecto | 401 o 403 |
| Horario con fecha inválida, pasada o duración inválida | 400 |
| Publicar bloque futuro propio y otro contiguo | 201 |
| Publicar bloque superpuesto | 409 |
| Modificar o eliminar horario ajeno | 403 |
| Mensaje menor a 10 o mayor a 500 caracteres | 400 |
| Dos usuarios reservan el mismo bloque simultáneamente | Una respuesta 201, otra 409; una reserva activa en MySQL |
| Bloque reservado en listado público | No aparece ni expone mensaje |
| Confirmar reserva como usuario o profesional ajeno | 403 |
| Confirmar como profesional dueño | 200 |
| Cancelar como usuario dueño y volver a reservar | 200 y 201; se conserva la reserva cancelada |
| Editar bloque con reservas históricas | 409 |
| Retirar bloque con todas las reservas canceladas | 200; conserva el historial |
| Listado privado de otro usuario | No devuelve las reservas ajenas |
| Reactivar reserva cancelada | 409 |
| Alternar lista/mapa | Conserva filtros y página; sin nueva consulta de resultados |
| Seleccionar marcador | Abre nombre y enlace a ficha mediante SDK simulado |
| SDK no disponible | Mensaje y resultados accesibles; permite reintentar |
| Google Maps real | Pendiente de clave del proyecto |
| SMTP y entrega real | Pendiente de credenciales; no se envió correo |
